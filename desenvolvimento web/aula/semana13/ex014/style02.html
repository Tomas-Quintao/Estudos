CSS INTERNO

Um estilo interno é aquele que fica configurado dentro da área do <.head.>

a grande vantagem dessa maneira em relação ao modo inline é a posibilidade de escrever uma Configuração única para todos os elementos da mesma familia. Por exemplo, todos os paragrafos deste documento estão com a mesma configuração de cor, e eu so preciso escrever isso uma vez.

A grande desvantagem deste modelo em relacao a ultima estrutura que

veremos é que no CSS externo (a estrutura do proximo exercicio é que o estilo não pode ser reaproveitado por outras páginas )

importante: Você pode misturar o CSS inline com o CSS interno em um mesmo documento sem problemas! vamos fazer um pequeno TESTE! É deste processo de que aplicamos os estilos em diferentes níveis que surge o conceitos de "FOLHAS DE ESTILO EM CASCATA"
